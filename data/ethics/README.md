# Unit 2 ethics screen results

This table transcribes the results of Phil's own 27-question screen, described in his [AI-ethics guide](https://tidyweb.github.io/ethical-considerations-in-ai/). It records the first-pass findings for the Unit 2 project for use in the Unit 3 second look; it does not re-evaluate the answers. A yes is a concern to investigate, not a finding of harm. A no-flag means no concern was raised, not that the project is safe.

## Columns

- `q`: question number from the screen.
- `checkpoint`: checkpoint letter A–F.
- `checkpoint_name`: full checkpoint name.
- `question_short`: short wording from the screen report.
- `legal_trigger`: `true` for Q5, Q6, Q12 and Q26; otherwise `false`.
- `lamp`: `concern` for a yes answer, or `no_flag` for a no answer.
- `severity`: `low` only where the report labels the concern low; otherwise blank.
- `stages`: Unit 3 stages linked to each concern, separated by semicolons. `cleared` means no concern was raised for that question.
- `evidence`: the evidence recorded in the report.
- `action`: the action recorded in the report.
- `plan_ref`: the report's plan reference.
- `status`: `open` for every concern and `n/a` for every no-flag.

The six stage names are S1 Choosing sources; S2 Preparing and aggregating; S3 Joined table; S4 Hypothesis test; S5 Machine learning; S6 Hotspots; and S7 Dashboards and site.
